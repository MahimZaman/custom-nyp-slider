# Custom NYP Slider

Adds a slider for WooCommerce Name Your Price products.

## Installation and use

Place the `custom-nyp-slider` directory in `wp-content/plugins/` and activate **Custom NYP Slider** from the WordPress Plugins screen.

Requires WooCommerce and Name Your Price. The slider is intended for products configured to accept a customer-entered price.
